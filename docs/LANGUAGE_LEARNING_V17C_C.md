# SIRA v1.7C-C — Research Query + Runtime Skill Integration

This stage connects verified multilingual understanding to real Research Mesh query execution and connects protected successful promotion outcomes to reusable local skills.

Research query preparation is local-first. English stays model-free. Bangla/Banglish/ambiguous input may use the existing teacher+verifier only when explicitly enabled and the existing zero-cost guard permits it. If that bridge is blocked, research falls back to original or already-consolidated local language knowledge and never labels the fallback as a verified translation.

Skill evidence is accepted only from a handoff proving `status=promoted`, `outcome=promotion_committed`, main-tree modification, and a passing measured structural check. The handoff ID is the evidence identity. Three distinct successful protected handoffs are required before the existing consolidation store activates a skill. Failed handoffs do not create successful skill evidence.

A consolidated skill may be supplied to a future writer hypothesis as advisory context only. It cannot bypass research, tests, benchmarks, Evaluator 2, protected Evaluator 1, transactional promotion, access controls, or spending/billing policy.
