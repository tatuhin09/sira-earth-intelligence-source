# SIRA first slice implementation plan

**Goal:** Deliver an install-free Python research retrieval starter with one API.
**Architecture:** Injectable provider protocol, single controller, JSON storage.
**Tech stack:** Python 3.10+, standard library, unittest, local Git.
**Spec:** ../specs/2026-09-17-stage1-design.md

The user requested implementation now, using the finalized architecture. Execute
inline with checkpoints, and deliver the complete small source package.

1. Create an isolated new project and venv; initialize Git.
2. Write behavioral tests before implementation. Run
   `.venv/bin/python -m unittest discover -s tests -v` to observe missing behavior.
3. Implement the contracts, settings, persistence and offline controller. Run the
   same command; inspect IDs, JSONL events, references, cache and unknown metrics.
4. Implement the Tavily adapter against official documentation checked today.
   Exercise the real adapter with a substituted HTTP transport; no live credits.
5. Run `python sira.py benchmark`. Validate each fixture expectation and confirm
   `api_requests=0`. Store run and dataset/code hashes for reproducibility.
6. Check `.env`, runs, cache and venv are ignored; commit source with tests.
7. Package complete source, tests, docs and a baseline verification report.
   Deliver Ubuntu extraction, venv, tests, Git and first live-search instructions.

User checks each command's expected result before advancing. Live API success
must not be claimed until a real authenticated request has been made.
