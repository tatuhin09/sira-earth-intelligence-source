# Source evidence implementation plan

**Goal:** Turn existing search runs into auditable, readable source evidence.
**Architecture:** Bounded cloud extraction -> typed documents -> quote records ->
JSON/Markdown/HTML, preserving the original run and quality-score uncertainty.
**Spec:** ../specs/2026-09-17-evidence-design.md
**Stack:** Python 3.10+ standard library, Git, unittest.

1. Write tests for partial responses, exact URL matching, malformed/unsafe input,
   redacted failures, cache reuse, parent immutability and rendered injection.
2. Implement providers/http_json.py and providers/tavily_extract.py. Preserve
   search adapter compatibility; test both against mocked HTTP responses.
3. Implement reading.py and reports.py with parent SHA-256, document records,
   exact quote offsets and new run IDs. Test offline with literal fixtures.
4. Add CLI read/benchmark --reading; version the synthetic benchmark separately
   from the existing retrieval suite. Verify all old and new tests.
5. Review concrete failure/security paths. Fix only demonstrated issues.
6. Build guarded update and prove clean installation, reapplication and modified
   target rejection. Package complete changed/new files and Ubuntu instructions.

Live extraction requires the user's local credential and is not claimed tested
unless a real authenticated request has occurred. No credential is requested in
chat. Review output, not arbitrary environment or .env contents.
