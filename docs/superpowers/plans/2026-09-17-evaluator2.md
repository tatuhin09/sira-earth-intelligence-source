> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add deterministic candidate diff/risk inspection and an auditable non-promoting Evaluator-2 decision.

**Architecture:** `src/sira/evaluator2.py` scans the trusted main public tree and isolated candidate without following symlinks, computes a bounded structural diff, and combines it with existing experiment health results. `run_experiment()` persists this report and rejects structurally unsafe candidates before any future promotion gate.

**Tech Stack:** Python standard library, unittest, existing SIRA improvement/self-modification modules.

**Spec:** `docs/superpowers/specs/2026-09-17-evaluator2-design.md`

## Global Constraints
- No main-tree promotion in v1.0B-2.
- Evaluator 2 executes from the trusted main process, never candidate code.
- Baseline health, candidate unit tests, relevant benchmark, protected-path integrity, allowed-path integrity, text-only diff, symlink rejection, and edit bounds are mandatory.
- Unchanged regression-check candidates remain valid `no_change_verified` results.
