# SIRA v1.7D-C — Autonomous Knowledge Reuse and Revalidation

Fresh multi-source verified knowledge is reused locally before research and performs
zero network/model calls. Opportunity research may include fresh local knowledge as
advisory strategy context, but this cannot satisfy the existing writer-ready gate.

Stale or conflicted knowledge can become a lowest-priority
`knowledge_revalidation` target after memory failures and proactive code
opportunities. Revalidation is read-only free/public discovery, has a 24-hour
anti-loop cooldown, and never enters code-writer, promotion-lease, evaluator, or
source-modification paths.

Discovery never changes durable knowledge. A refresh still requires independently
read evidence followed by the existing verified synthesis -> consolidation bridge.
No owner, billing, spending, evaluator, or promotion authority is added.
